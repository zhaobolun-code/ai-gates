# 修复证据黑板（反例）

> 路径：方案夹 `证据/_repair-blackboard.md`（本模板复制后维护）。  
> **用途**：防止失忆式重复试错。派实现/交审修复/CR 时注入**最近 ≤3 条**；全文可留在证据夹。  
> **默认禁扫 `证据/`**：仅当派发/PM **点名本文件**时可 Read（见 doc-windowing）。

## 条目格式（追加，勿改历史条）

```text
### 尝试 {n} · {日期或 Step/热修标签}
- **触发**：测挂 | CR blocker | AI 验收不通过
- **改了什么**：符号/文件 + 手法一句（勿贴大 diff）
- **为何失败**：对照 A# / 现象一句 + 证据路径或关键词
- **禁止再做**：一句反例（下一刀不得换皮重试）
- **有意义评审**：有 | 无 | 部分有
- **保留原因 / 已撤**：有→保留原因+下一刀禁重复；无/部分有→已撤范围一句（定向撤，禁 hard reset）
```

## 规则摘要

1. 测挂或交审级修复失败后 **同条追加** 一条（PM 或程序员；禁空话）。
2. **再改码前须有本条有意义评审**（三选一）；无意义/测偏禁同 A# 热修，须定向撤后换思路 Discover（diagnosis §0.2.1）。
3. 开始下一刀改码前必须 Read 最近 ≤3 条；派发提示词须粘贴或点名本文件。
4. 与「禁止再做」实质相同的手法 → 不得再选；CR 见则 major/blocker。
5. 止损触顶 / `max_repair_rounds` fuse → **停止往黑板堆改码尝试**，改走 A#/口径复议（diagnosis）。
