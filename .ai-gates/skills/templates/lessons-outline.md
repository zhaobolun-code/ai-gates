# 错题大纲（项目专属 · 模板）

> 复制本文件 → 仓库根 **`.ai-gates/lessons-outline.md`**。  
> **用途**：按桶分类，提高检索命中；每条必须含 **错因** + **改正**，提高改对概率。  
> 细则 → [references/lessons-learned.md](../references/lessons-learned.md) §错题大纲。  
> **禁止**把主表全文粘进大纲；每桶建议 ≤8 条高频。

## 怎么用

1. **策划**：写 Mandatory 前扫相关桶 → 打开主表对应行 → 在 `未完成.md` 写「## 错题本必读（给程序员）」  
2. **程序员**：只读必读节点名的大纲条 + 主表行（禁全表）  
3. **晋升**：新 L1「准」入库后，若属高频桶，同条或下轮维护把该条链进大纲（含错因/改正）

## 条目格式（每条）

```markdown
### 短标题（≤20 字）
- **主表锚点**：YYYY-MM-DD / 模块名 / 症状关键词
- **错因**：为什么会错（机制一句，禁只写「又挂了」）
- **改正**：应该怎么改才对（可执行动作一句；可含复用哪个 helper/门闸）
- **类型**：方案blocker|CR blocker|运行时bug|自引入bug|Skill流程|成功经验
```
