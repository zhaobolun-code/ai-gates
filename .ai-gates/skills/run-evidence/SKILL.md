# 跑命令

首行：**`[run]`**。本技能由主窗调用。主窗自己不跑终端。

## 何时由主窗调用

主窗要跑编译、测试、脚本或其它命令，先读本页，再派子窗。查日志只看已经落盘的输出，不负责开命令。程序员子窗按方案改代码时自己跑命令，不经过本技能。

## 主窗怎么派

1. 读 `.cursor/project-context.md` §模型路由，取「跑命令」行的 `model=`。禁止省略，禁止 `inherit`。
2. 派子窗。提示词只给：要跑的那一条命令、要回答的问题、下面三行格式。禁止把已有长输出贴进提示词。
3. 子窗返回后，主窗只保留那三行。禁止把命令输出再展开进回复、交接或 `未完成.md`。

## 子窗

只跑主窗点名的那一条命令。不改文件。不发 `[PM]`。不读大源码，不全库搜索。

交回只许这三行：

- 跑了哪条：命令
- 结论：退出码，加一句
- 还没证明什么：一句

编译通过、单测绿，都不等于人已经看见现象。命令没跑成就写「没跑成」，不要编。
