# 书写习惯

给人看的正文用这份。对话里的进度说法仍以 [user-visible-states.md](./user-visible-states.md) 为准。周报骨架仍以 [weekly-report.md](../templates/weekly-report.md) 为准。模块 README 该有的节仍以文档岗为准。

这份不管检测器。读的人觉得对面有人，就够了。

英文里常见的腔，来自 [blader/humanizer](https://github.com/blader/humanizer)（MIT）。简体中文多出来的腔，来自三份 MIT 技能的浅克隆，只留习惯，不抄清单和范文：[jiji262/humanizer-chinese](https://github.com/jiji262/humanizer-chinese)、[LifelongLazyLearner/qu-ai-wei](https://github.com/LifelongLazyLearner/qu-ai-wei)（先前看到的 xieincz 分叉停在五月，克隆的是还在更新的上游）、[MrGeDiao/shuorenhua](https://github.com/MrGeDiao/shuorenhua)。克隆在 `.ai-gates/tmp/`，不进发布包。

## 先分清写给谁

| 写什么 | 怎么用这份 |
| --- | --- |
| 首页、使用说明、对话里给人看的几句 | 全用。第一句写读者此刻会碰到的事。 |
| 周报、日报 | 章节名、正式口径、只写已经做完的事，都不改。只删腔。 |
| 模块 README | 概述、约束、结构、原理、调试、版本记录都留着。能一行版本记录说清，就不要再开一章原理。 |
| 给助手看的技能正文 | 可以短。短不等于每句前面垫一句「值得注意」。 |

读者已经知道的，不要再讲一遍。缺数字、人名、日期，写还不知道，或者去问。不要编一个出来显得具体。

命令、路径、链接、表头、代码，不要为了顺口改掉。

## 写的时候

先写这件事本身。

别这样：让 AI 按风险组织开发流程，让你保留关键决策权，并且不把没跑过的测试说成通过。

这样写：小改动它直接做。要是会动到以前存的数据，它先写个方案，你说行再改代码。测试没跑，不能写成通过。

一句能说完，就不要先否定一句再转折。

别这样：这不是又一套技能清单，而是一套项目里的规矩。

这样写：它管的是这件事该不该先停一下。

段尾不要再补一句金句。上一句已经说完，就停。

不要凑成三项。有两条写两条，有四条写四条。「快速、可靠、可追溯」这种并列，改成你实际要说的那一件。

不要先垫话。「说实话」「简单来说」「让我们看看」删掉，直接进入那句。

不要跟没人提出的反对意见辩论。没人问「会不会完全自动」，就不要写「我不是说它会完全自动」。

假深沉换成具体的事。

别这样：真正重要的，是长期价值与信任的闭环。

这样写：同一个坑第二次再改到这块，检查会更严。

结尾停在最后一件事实。不要「未来可期」，不要「这将为后续奠定基础」。

句子长短跟着意思走。一句很短，可以单独成段。不要每段都一样长。

信任读者。步骤他看得懂，就不要再解释你为什么分成这三步。

「深入」「赋能」「闭环」「抓手」「落地」「对齐」改成做了什么。只换词不够。换完读一遍，还是同一节奏，就重写这一段。

加粗只留给读者必须看见的那几个词。小标题写这段在讲什么，不要用口号，不要加表情。

不要「好问题」，不要「希望这对你有帮助」。

## 中文里另外要注意

换到任何题目都能用的开头，删掉。

别这样：随着人工智能的不断发展，开发流程已经发生了深刻变化。

这样写：AI 改完常常说做好了。你一试，旧配置打不开。

事实说完，不要再挂一小句「，体现了」「，彰显了」「，进一步凸显了」。

「标志着」「奠定了坚实基础」「翻开了新篇章」改成那件事本身是什么。

「对反馈进行深入分析，对功能作出调整，对问题予以解决」写成「看反馈，改功能，把问题处理掉」。周报要书面时，留一处「进行」可以，不要三处连着来。

英文句子的骨头留在中文里，要拆开。「作为一个复杂的系统，它的性能在很大程度上取决于它的架构被设计的方式」写成「这个系统复杂，好不好用主要看架构怎么设计」。一串「的」叠在一起，拆短。中文本来就可以不写主语，「不用另开网页服务」是正常说法，不必补成「它不需要被启动」。

一个成语不用删。四个四字词对仗排开，才要拆。

没有明显好处，就别改这句。代码、命令、数字、「可能」「计划」「已经」这些词的意思不能为了顺口换掉。只换几个词、节奏还是一样，就把句子重写。

不要装成聊天。不要编一段「我当年」。不要每篇都加「说白了」「靠谱」「吧」「嘛」，也不要故意写错别字。首页可以对着人说，周报和模块说明保持书面。平实就是对的，不必再涂一层口语。

## 周报和日报

仍是书面语，给同事和上级看。不要改成聊天，不要加「吧」「嘛」，不要拆成人做的和 AI 做的。

套用时只查三处：段尾有没有金句，有没有为了整齐凑成三项，有没有「标志着」「值得注意」「全面提升」。材料里没有的句子不要补。

别这样：本周对实验稳定性进行了全方位优化，标志着后续维护迈上新台阶。

这样写：本周核对了导管分层的编译和单元测试，并改了端口分界，层宽随传感器写回。

## 写完读一遍

问三句。

第一句是不是这件事本身。

有没有哪句只是在重复上一句。

有没有哪句是为了显得像人，才加上去的感叹。

还有腔，就改那几句。不要整篇换成更华丽的词。

这份若读起来像在手把手教写作课，就是它自己没写好，应再收短。
