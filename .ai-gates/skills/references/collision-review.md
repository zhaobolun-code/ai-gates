## 模型配对（硬）

三槽必须是**三个不同模型**（Cursor slug；本机无该槽则按 [model-routing.md](./model-routing.md) 回退，仍须本轮两槽不同；无法异模型 → **终止碰撞**，降级普通隔离审，并标注「未按模型路由」）：

| 槽 | 模型 | slug |
| --- | --- | --- |
| Grok | Grok 4.6 | `cursor-grok-4.6-high` |
| Sonnet | Sonnet 5 | `claude-sonnet-5-thinking-medium` |
| Terra | GPT 5.6 Terra | `gpt-5.6-terra-medium` |

| 轮 | 配对与角色 | 本轮禁止 |
| --- | --- | --- |
| **0** | 建议 = 轮1 两槽；各报前提 → **共识地基三句话** | 写方案；点名源对不上却标「一致」 |
| **1** | **Grok = 构建者** × **Sonnet = 红队** | 同模型双链；角色对调；开头不引用地基 |
| **2** | Terra × Grok；**引用原文只投票** | resume 轮1 同一对；重写分歧描述 |
| **3** | Sonnet × Terra；**引用更窄原文只投票** | 第四模型全量再审；扩大分歧范围 |

每一轮两个 Subagent **必须**显式不同 `model=`。禁止同模型开两条链。禁止用 `resume` 让上一轮同一对继续当本轮双方。

## Procedure

派发协议一律 = [isolated-review.md](./isolated-review.md) **最短派发包** + ACK；禁止注入父窗未入库讨论。

### 轮 0 — 前提碰撞（必做 · 可截断）

两隔离槽各只输出 **1 条最强前提**（≤5 行）。点名的数据源 / 表名 / 工件对不上 → **视为不一致**（假一致），不得标「一致」。不一致 → **终止**，主窗回报「需求歧义，请澄清后重试」，**不得**进入轮 1–3。

一致 → 主窗**机械**写出可引用的 **共识地基**（只许用双方已写出的词，禁止发明新约束），强制三句、全文 ≤5 行：

```text
共识地基：
1. [共同认可的业务目标]
2. [共同认可的技术约束（含双方点名的数据源/表名）]
3. [共同认可的成功标准/验收红线]
```

此三句是轮 1 的契约文本，不是方案。轮 1 派发必须粘贴原文。

### 轮 1 — 唯一「盖 vs 拆」轮（显式角色）

被审查对象必须是**方案工件**，不是轮 0 那一条前提。Grok / Sonnet 的输出**开头必须逐字引用**共识地基三句；缺引用 = 违规，红队可打「地基偏离」。

| 场景 | 工件 | Grok（构建者） | Sonnet（红队） |
| --- | --- | --- | --- |
| **从零**（尚无方案） | 轮 0 地基上 Grok 新写的方案 | **出完整方案**（开头引用地基） | 只看该方案，Top 3 风险，不写全文 |
| **审查已有方案** | 已有方案夹（未完成 + 口径 + Mandatory） | **禁止再写一份方案**；风险清单**开头引用地基** | 只看同一份工件，Top 3，不写全文 |

红队提示词按对象换弹种（Skill/Doc 默认：A# 不可证伪 / Mandatory 与验收不同句 / 跨源口径或契约断裂）。禁止写死外域「API 500」八股。

**定级锚（硬）**：`blocker` / `major` / `minor`；禁止平行 P0/P1/P2。每条必须绑 **A# 编号** 或 **Mandatory 路径** 或 **机器检查现象**。缺锚不得升 blocker。

> **脚注 · 锚**：下文「锚 / 按锚对齐 / 带锚」一律 = 本条定级锚（三选一）。短清单按此键对齐，不是新术语。

### 短清单（轮 1 强制产出 · 主窗机械拼装）

隔离槽**不能联合拟稿**。两边各自交断言（须带定级锚）。主窗只做机械拼装：按定级锚对齐；**禁止改写断言**。

- 同锚且判断相同 → **已消**，标共识项，写入收尾消解记录，**不进轮 2**。
- 同锚判断不同，或仅一方提出 → **未消**，进入轮 2。

拼装后每条：

```text
分歧点 N：
- Grok 判断：[逐字]
- Sonnet 判断：[逐字]
- 已消掉：[是|否]
```

**短清单 = 仅「已消掉: 否」的条目**。不是完整方案，不是 Top 3 原文。可另附共识标题栏（已消项一行标题，禁止展开）。

### 轮 2 / 3 — 引用原文只投票

- **轮 2** 输入 = 轮 1 未消条目原文。配对 Terra × Grok。
- **轮 3** 输入 = **轮 2 之后仍未消**的条目原文（逐轮收窄）。配对 Sonnet × Terra。
- 每票强制格式（禁止改引用段）：

```text
[引用上一轮该条原文，逐字复制，不修改]
---
我的投票：[支持 Grok / 支持 Sonnet / 第三条路]
证据（≤3 条，每条 ≤20 字）：
1. ...
```

- **禁止**：重写分歧描述、加新事实假设、证据超过 3 条、重写/压缩方案、扩大分歧范围。
- 轮 1 若零未消：仍跑轮 2/3，输入只有共识标题栏，只允许「这条站不住 + 锚」。轮 0 终止除外。

### 收尾 — 薄归并（不是再审）

主窗 PM 或一个隔离窗只做归并，禁止第四次全量评审。计的是**判断**，不是模型人格票。**第三条路若未被任何一方覆盖，计为独立票，不降权。** 禁止用 0.5 等分数票。

1. **多数决**：同一判断在 ≥2 轮被支持 → 采纳。
2. **逻辑翻转（震荡）**：同一模型对同一分歧点，轮 2 与轮 3 **支持了对立双方**（如先挺 Grok 后挺 Sonnet）→ 该模型本条**不计票**，记震荡。理由换措辞 ≠ 翻转。
3. **视角升级**：同一模型轮 2 支持一方，轮 3 提出**未被覆盖的第三条路** → **计独立票，不降权**，与多数并列，标「需你拍板」。不得当震荡、不得改 0.5。
4. **残留**：没有任何判断拿到 ≥2 轮支持（且无待拍板的新路径）→ **不硬并**，写入 `证据/_lesson-pending.md`，确认包问拍板。本次碰撞若是开工前审查，未决挡住「准实施」；不得在未启用碰撞的任务里私自停工。

输出是**分歧消解记录**，不是最终方案。

### 回灌（入池门槛硬 · 改规则仍须「准」）

两层不要混称「入库」：

| 名字 | 路径 | 是否生效 |
| --- | --- | --- |
| **pending（待确认）** | 当前窗 `证据/_lesson-pending.md` | 软入池，**不生效** |
| **错题本（主表）** | `.ai-gates/lessons-learned.md` | 仅用户「准」后生效 |

写入 pending（`来源：思考碰撞`）当且仅当满足**任一**：

- **跨轮重现**：同一异议在 ≥2 个不同配对中被独立提出（不论当时是否采纳）；
- **杀伤半径**：绑了具体 A# / Mandatory，并断言该条会失败。

收尾可**人工**对照 anti-patterns 标「候选新类」；禁止新做关键词比对脚本。实质「我不知道」→ [knowledge-gap.md](./knowledge-gap.md) 三要素，不与 pending 混表。

用户「准」→ `commit-lesson-pending.ps1 -Apply`：pending → **错题本主表**。**禁止**自动迁入反模式库 / 改 Skill；**禁止** 7 天超时进主表或自动「已拒绝」（沉默 = 留在 pending，不进主表，见 [lessons-learned.md](./lessons-learned.md)）。

## 禁止

- 同模型双链；`resume` 同一对顶替异模型轮转；轮 1 角色对调冒充本表。
- 轮 1 输出开头不逐字引用共识地基；审查已有方案时构建者再写完整方案。
- 主窗改写双方断言来「整理」短清单；轮 2/3 重写分歧描述或压缩方案。
- 把 Top 3 / 完整方案当短清单；把第三条路（视角升级）当成震荡不计票或改 0.5 降权。
- 默认 5–8x，或多轮直到共识（本手续至多轮 0+3）。
- 用碰撞替代 L1.5/L2 隔离审；专职第三窗全量再审；平行 P0/P1/P2；震荡用 0.5 权重。
- logits 熵；第二套队列；pending 与 KG 混表；超时自动入库。
- 常规任务默认启用；把加载当启用；止损触顶/热度单独触发。提示 ≠ 启用。
- 把 [divergence-annotation.md](./divergence-annotation.md) 单轮链写成「完整碰撞已落地」。
