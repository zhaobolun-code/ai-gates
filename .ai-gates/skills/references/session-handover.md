# 会话交接（Session Handover）

> 权威：跨 Chat / 换模型续跑同一方案时的**八段摘要**，并附加「新窗第一句」复制块。  
> 接线：[handoff-automation.md](./handoff-automation.md) §J。可粘贴空表 → [templates/session-handover.md](../templates/session-handover.md)。  
> 与岗位内交接块 [handoff-template.md](./handoff-template.md) **互补**（本文件专治跨会话；后者专治同会话转岗）。

## 目标

少交接翻车：下一会话只靠本摘要 + `未完成.md` 即可续，无需重读主对话。长 Chat 卡顿换窗时，用户可复制「新窗第一句」到新 Agent Chat 续作。

## 八段字段（钉死 · 缺一不可）

| # | 字段名 | 写什么（白话、短） |
| --- | --- | --- |
| 1 | **当前状态** | 文档状态 + Step + Auto 步数/`stop_reason`（若有） |
| 2 | **已做** | 本窗已落地/已签收要点（≤5 行） |
| 3 | **下一步** | 下一刀具体动作（做 Step N / 等测 / 结案） |
| 4 | **禁区** | 明确不改什么（文件/范围/口令旁路） |
| 5 | **依赖** | 前置：已「准」、revision、Unity、外部材料 |
| 6 | **风险** | 已知坑 / soft risk / 行数债（可无则写「无」） |
| 7 | **证据路径** | 方案夹、点名派发、夹具路径（禁灌全文） |
| 8 | **下一口令** | 用户下一句该回什么（如「本窗 Auto」「测试通过」） |

## 新窗第一句（附加 · 不替代八段）

命中触发时，主 Agent **必须**在聊天输出一块 **fenced `text` 代码块**（字段名钉死、顺序固定），供用户复制到**新** Agent Chat。块首须有对模型的指令：你是接手当、不要重读旧 Chat、先读【先读】路径再动手。块内须含一句事实：本窗 Agent 不能自动新建 Chat，须用户复制到新 Agent Chat。

字段顺序（不可改名、不可重排）：

1. **任务**
2. **已落地**
3. **未完成**
4. **禁区**
5. **先读**
6. **旧窗检索**
7. **请直接做**

【先读】只写路径（可含 project-context 认知卡片节）；禁止把 F/R/A/S 粘进交接。

空表见 [templates/session-handover.md](../templates/session-handover.md)。

**与八段的关系**：新窗第一句是**附加**，不替代八段，不自造第九段替换八段字段名。聊天可贴八段 + 新窗第一句；推荐落盘仍是 `证据/_handover.md`（八段）；新窗第一句以聊天复制块为主，不必强制另存；若落盘可放在同一 `_handover.md` 后半，`未完成.md` 仍只留一行指针。

## 提示换窗（≠ 执行交接）

本会话**用户发言条数 ≥ 20**（只数主对话用户消息；不含助手、不含子窗、不含工具结果；一条 `user_query` = 1 轮）时，主窗 PM 须在「你下一步」附一句短人话：建议回「换窗」。

- **每窗最多提示 1 次**；用户回「先不换」后本窗不再提示。
- **未到 20** 不得因「感觉上下文长了」提示。
- **提示 ≠ 执行交接**：≥20 轮 **禁止**自动输出八段 / 新窗第一句；须用户说「换窗」/「交接」等（见下节触发）才吐复制块。
- **唯一提示条件**：只认用户发言 ≥20；禁止另开「2 轮实现+审核」或其它密度阈值。

## 触发（须输出或落盘）

任一条命中 → 主 Agent **必须**按上表生成八段摘要（聊天可贴全文；推荐另存 `证据/_handover.md`，`未完成.md` 首段只留一行指针），**并**附加「新窗第一句」fenced `text` 复制块：

1. Auto `await_human reason=max_auto_steps`（预算用尽）
2. 方案将迁 `completed` / 已结案交接
3. 用户说「交接」/「换 Chat」/「handover」/「换窗」/「卡了」/「卡了换窗」

**不算触发**：普通 `reason=unity_test` 待测（可用更短「你下一步」）；上下文长度触顶 / 压缩 **也不**自动交接、**也不**另开第二套提示阈值（提示只认上节用户发言 ≥20）。

## 禁止

- 粘贴 `已完成/**` 全文、长 Console、整份主对话（含旧对话全文）写入八段或**新窗第一句**
- 把认知卡片的 F/R/A/S 写入八段或新窗摘要当现行认知（只留「去读 project-context 认知卡片节」）
- 自造第九段替代上表八段字段名；用新窗第一句七字段冒充/替换八段
- 用 handover 静默改码或跳过「准」/待测闸
- 指望本窗 Agent 自动新建 Chat（无 API；须用户复制新窗第一句）
- ≥20 轮仅因提示条件自动吐八段 / 新窗第一句（提示 ≠ 执行交接）
