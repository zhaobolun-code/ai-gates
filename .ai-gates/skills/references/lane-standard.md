# Standard

1. 扫错题大纲。命中写日期或关键词一行，否则写「已扫，无命中」。
2. 一个方案夹。活跃正文在 `未完成.md`。复用四问、选型、可证伪 A#、Delta 写在当前 Step。
3. 方案审没有 blocker，再发一次确认包。包里只写「准」。
4. 「准」之后派程序员子窗，显式 `model=`。
5. 改完派隔离代码审。业务 C# 的交审材料要有可执行的 Unity 步骤或 Console 关键词；没跑就写 `not run`。没有 `hooks-log/cr-stamp.json`，不能把状态写成审完。这枚戳记只许代码审核子窗写。
6. 这一刀含业务 `.cs` / `.lua` 且还要人测：运行 `scripts/set-knife-state.ps1`，写下待测、窗名、A#、现象句、热修次数、当前车道。同一窗、同一 A#、同一句现象再热修，次数加一。

有 blocker 不定版。命中 CORE 的 Full 强制条，改用 Full 卡。
