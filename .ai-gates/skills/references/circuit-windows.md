# 电路子窗（契约串/并手续）

> **电路子窗**。定位=策划写 ≥2 Step 契约时强制拆 **串联/并联** 步骤，用墙钟加速；显式 **不是岗**。岗位路由表不加行。禁止 `circuit-job` / 第八岗。
> **加载 ≠ 减 CR**。点名本页或写 ≥2 Step 契约时加载。战役模式可跳过**重复方案审**（口径未变），**不得**跳过每刀隔离 CR。

## 串并联

| 模式 | 何时 | 派发 |
| --- | --- | --- |
| **串联** | 后步 depends-on 前步产物，或抢同一生效文件 / 同一神类净增 | 前步 CR 无 blocker 才开后步 |
| **并联** | 文件集合不相交、无数据依赖、A# 可独立证伪 | PM 可同时派多个实现子窗 |

**能并则并**：默认能并则并。故意写成 1→2→3 但 Mandatory 文件不交、也无 depends-on → 方案审 **major**（假串联）。

**路径相交改串**：路径集相交 → 必须串联（不得标并联）。

加速来自拆步与战役减重复方案审，不来自减 CR。并联每条支路仍要可证伪 A# + 隔离 CR（不因并联降档/跳 CR）。汇合后须一句集成维。不写自动拓扑调度脚本。PM 读契约串/并再派 Task。

## 战役模式（同窗同口径连续刀）

> 减的是**重复方案审**，不是减 CR、不是减「准」、不是减 A#。

| 条件（须同时） | 手续 |
| --- | --- |
| 同一方案夹、同一 `物理口径.md`、选型短表与 A# 契约相对上一刀无实质变化 | **不派**方案审；PM 在派发写 `campaign: yes` + 上一刀 Step 号 |
| 口径 / 选型 / A# 契约相对上一刀有实质变化 | 当刀恢复方案审（档位仍按车道） |
| 每一刀实现收口 | **仍**隔离 CR；有意义评审 / 黑板 / 止损照旧 |

**完成即迁移**：战役中可将 Step 正文留到签收或每 N 刀一批再写入 `已完成/` + `_索引.md`；`未完成.md` 仍只留当前摘要。非战役仍本 Step 收口即迁。签收 / 失败 / 回退终态仍须 `migrate-pipeline-window`。
