# 外仓对照（可选 · 点名才开）

> **加载本文件 ≠ 启用**。常规任务不搜、不下载外仓。PM 判定该用 → **只提示**；用户点名「外仓对照」才跑。
> 外仓代码**禁止直接复制**进本仓。必须先读本仓真实代码（硬门禁 #1），外仓只作结构参考。

## 定位

对照公开仓库里**类似能力的结构**（怎么拆职责、怎么接线），帮本仓少走弯路。

**不是**：抄类名 / 抄路径 / 抄测试清单 / 替代本仓复用四问 / 第七岗 / [research-task.md](./research-task.md)（API/文档事实）/ [collect-queue.md](./collect-queue.md)（典故错题收集仓）。

## 用途分级

| 级 | 条件 | 动作 |
| --- | --- | --- |
| **常规** | Express / Direct；或本仓已有明显同类实现 | **不启用、不提示** |
| **提示** | Standard / Full，且复用四问「已有吗」= 本仓无明显同类（绿场 / 新能力） | PM 在「你下一步」写一句可选「外仓对照」；**未点名不搜、不 clone** |
| **启用** | 用户点名「外仓对照」（含回复「用外仓对照」） | 跑下列手续 |

加载 ≠ 启用。提示 ≠ 启用。禁止每窗必搜 GitHub。禁止把提示写成已经对照过。

本仓已有热路径真源（如压力/气液）时，默认不提示——外仓几乎对不上，抄了会坏物理口径。

## 启用后手续

1. **先本仓**：读 project-context、范围内 README、真实符号。外仓对照**不豁免**硬门禁 #1。
2. **短清单 ≤3**：每条写仓 URL、许可、像在哪、不像在哪。禁止无出处「网上都这么写」。
3. **下载**：仅克隆到 `.ai-gates/tmp/ext-{短名}/`（不入库；环节收尾清空）。**禁止**写入 `Assets/`、`Packages/`、业务目录。许可不明 / 禁止再分发 → 不 clone，只读公开页当参考并标注。
4. **只抽结构**：写入本窗 `证据/external-compare.md`（结论先行 ≤5 行）：参考了什么结构、明确不抄什么、本仓落到哪些已有符号。禁止把外仓路径/类名写进 Mandatory。
5. **选型短表**须有一行「不选照抄外仓」（Why Not Chosen + 负向代价：对不上本仓接口 / 物理口径 / 自由装配）。
6. **落地只改本仓**：程序员按本仓 helper / Service / 门闸写；对照过 ≠ 可以粘贴外仓文件。

调研子窗若使用：只读，产物进 `证据/` 或 `.ai-gates/tmp/`，**不定方案**。决策仍归方案审 + 确认包。

## 禁止

- 默认接到需求就搜 GitHub / clone。
- 把外仓文件、类名、路径、测试清单复制进本仓。
- 用外仓绿 / 外仓 star 数冒充本仓 A# 通过。
- 第七岗 / `github-compare` 岗 / 平行对照表当 Mandatory。
- 跳过本仓检索，以外仓当开工图纸。
- clone 进 `Assets/` 或长期留在仓库跟踪目录。
