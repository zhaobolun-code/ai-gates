# 车道术语（v4 权威）

> **日常唯一路由**：`Express | Direct | Standard | Full`（见 [CORE.md](../CORE.md) §四车道判定）。
> 执行文档、交接块、复盘记录字段名统一用 **`车道`**，不再写「流水线模式」。
> v3（三车道）已于 2026-08-10 重构为 v4（四车道：新增 **Direct 直通道**）；旧文档按文末「车道名映射表」检索。

## v4 车道定义

| 车道 | 含义 |
| --- | --- |
| **Express** | 机械微改且**恰好 1 个**业务源文件：注释/日志/编译错/常量≤3 行；无 API/持久/跨模块；一句话 A#。有行为变化即使 1 文件 → Direct。回归索引/热度/路径不单独否决 |
| **Direct** | **PM 默认**。有行为变化，或机械但已 2～3 个文件；≤3 文件；无 API/持久/跨模块。对话内 A#/切片不落盘。Express/Direct 止损 → Standard |
| **Standard** | >3 文件 / 跨模块 / public API / 持久或序列化 / 说不清 / 快或直通第一次止损。plan-lite + CR。热度只加强审，不单独进本车道 |
| **Full** | 用户「完整流程」；或**已在 Standard 上再次止损**。禁止仅因文件数/存档/跨模块/路径就 Full |
