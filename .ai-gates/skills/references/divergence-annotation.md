# 分歧标注（两隔离槽 · 小试点）

> evolution-02 方向四**小试点**。5–8x 仍搁置；完整碰撞现行手续见 [collision-review.md](./collision-review.md)（异模型三轮薄碰撞）。指针签收 [evolution-02-meta-cognition.md](../../Doc/AI流水线/签收/evolution/evolution-02-meta-cognition.md) §方向四。本文件仍是小试点，**不是**完整碰撞的落地实现。**禁止**把本页写成「外源元认知已成立」。

## 定位

启用时用**两个隔离槽**各写一条视角推理链；有实质分歧 → **分歧标注** + 入队 `证据/_knowledge-gap.md`（`来源：分歧标注`）。碰撞 / 逆链当外源对抗手续成立；缺下列三条的分歧**不计入外源**。

可证伪手续（缺任一条 = 未做）：

1. **两个不同 id**：两个 Subagent/Task（或两个新 Chat）。禁止同一 Agent 单轮自写两链冒充已做。
2. **B 不见 A 的链**：B 的最短派发包不得注入 A 的推理链；禁止 `resume` A 当 B。
3. **未裁/对照不是 A/B 写的**：A、B 各自只交本视角推理链（建议 ≤15 行），**不得**写对照表、裁决、入队句。对照表与（有实质分歧时的）DA 入队句由**派发方**（父窗 PM/策划）根据双方未裁原文写。

非常规；点名 / 高危才启用；**不进**默认车道。禁止用本手续替代 [isolated-review.md](./isolated-review.md) 方案审/CR。不等于 [collision-review.md](./collision-review.md)（异模型三轮）。

## 用途分级（硬）

| 级 | 条件 | 动作 |
| --- | --- | --- |
| **常规** | 普通 Standard/Express 任务 | **不启用**；用 `isolated-review` 双轮审 |
| **启用** | 高危 / 止损触顶 / 跨模块大改（>3 文件或跨模块）/ 用户点名「分歧实验」 | 写 Mandatory 或策划切片前按上列三条派两隔离槽 + 分歧标注 |

## Procedure（两隔离槽）

1. 派发方列 ≥2 视角（例：物理口径 / 回归与门闸 / 范围与 A# — 按任务自选，须写清视角名），开**两个不同 id** 的槽。
2. 各槽只写本视角独立推理链（建议 ≤15 行），**不得**先写结论再补链，**不得**写对照表、裁决、入队句。B 包不得含 A 链；禁止 `resume` A 当 B。
3. 派发方根据双方**未裁原文**写对照表，列**分歧点**（一致则写「无实质分歧」并结束，不入队）。A/B 不得代写对照。
4. 有分歧：派发方为每条写 **DA-{nn}**（分歧句 + 两视角立场 + 阻塞/非阻塞），**转 KG 三要素**入队（上下文位置含 DA 编号；已尝试含本文件 procedure）。

## 与 isolated-review 边界

分歧标注治 **epistemic 分歧发现**（须满足上列三条）；**不替代** L1.5/L2/L3 隔离审。启用后的 DA 入队产物回灌 isolated-review 便宜隔离审（见该页）。禁止用本手续替代 Subagent 方案审/CR。

## 升级

同族分歧来源 KG 跨窗 ≥2 → 机制 A（`evolution-01`）。完整碰撞见 [collision-review.md](./collision-review.md)；本文件不实现 5–8x。
