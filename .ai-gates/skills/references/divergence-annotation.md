# 分歧标注（单轮多视角 · 小试点）

> evolution-02 方向四**小试点**。5–8x 仍搁置；完整碰撞现行手续见 [collision-review.md](./collision-review.md)（异模型三轮薄碰撞）。指针签收 [evolution-02-meta-cognition.md](../../Doc/AI流水线/签收/evolution/evolution-02-meta-cognition.md) §方向四。本文件仍是单轮小试点，**不是**完整碰撞的落地实现。

## 定位

同一 Agent **单轮**内显式产出 ≥2 **视角推理链**（分栏/编号，非 Subagent 互审），对照**分歧点**；有实质分歧 → **分歧标注** + 入队 `证据/_knowledge-gap.md`（`来源：分歧标注`）。

## 用途分级（硬）

| 级 | 条件 | 动作 |
| --- | --- | --- |
| **常规** | 普通 Standard/Express 任务 | **不启用**；用 `isolated-review` 双轮审 |
| **启用** | 高危 / 止损触顶 / 跨模块大改（>3 文件或跨模块）/ 用户点名「分歧实验」 | 写 Mandatory 或策划切片前可跑单轮多视角 + 分歧标注 |

## Procedure（单轮 · 非互审）

1. 列 ≥2 视角（例：物理口径视角 / 回归与门闸视角 / 范围与 A# 视角 — 按任务自选，须写清视角名）。
2. 各视角独立推理链（≤15 行/视角），**不得**先写结论再补链。
3. 对照表列**分歧点**（一致则写「无实质分歧」并结束，不入队）。
4. 有分歧：每条分歧写 **DA-{nn}** 标注（分歧句 + 两视角立场 + 阻塞/非阻塞），**转 KG 三要素**入队（上下文位置含 DA 编号；已尝试含本文件 procedure）。

## 与 isolated-review 边界

分歧标注治**单窗内 epistemic 分歧发现**；L1.5/L2/L3 **隔离审**仍照常；禁止用多视角链替代 Subagent 方案审/CR。

## 升级

同族分歧来源 KG 跨窗 ≥2 → 机制 A（`evolution-01`）。完整碰撞见 [collision-review.md](./collision-review.md)；本文件不实现 5–8x。

- 把本试点写成「完整碰撞」已生效，或默认每任务必跑多视角链。
- 本文件仍是单轮小试点，不等于完整碰撞已落地。
