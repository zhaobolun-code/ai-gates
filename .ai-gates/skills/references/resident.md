# 常驻

你说人话，它按这一刀选流程，没测过不许说通过。

四个固定词：没判定就改，没测就说通过，小改走了全套，同一错换皮再来。

做不到：本条判定看不见。读文件拦不住。Trae 没有钩子。Codex 桌面拦截未证实。

选车道按这个顺序，命中就停：

1. Full：命中 CORE 的 Full 强制条。
2. Express：恰好 1 个业务文件，且只改注释、既有日志或不超过 3 行的常量。有行为变化就不是 Express。
3. Direct：默认。有行为变化，或 2～3 个业务文件，且没有 API、存档、跨模块。
4. Standard：超过 3 个业务文件，或跨模块、API、存档、说不清。Express 或 Direct 第一次止损也升到这里。

判定之后只读一张卡，路径在 `skills/references/`：`lane-express.md`、`lane-direct.md`、`lane-standard.md`、`lane-full.md`。不要用搜索去找这四张卡。

要读代码或长文档、要搜索仓库、要跑终端、要看日志，先打开对应的一份再派子窗：`read-evidence`、`run-evidence`、`log-evidence`。这三份是必读，用到才打开那一份，不把三份全文装进每轮。主窗不自己读、不自己搜、不自己跑、不自己看日志。派发只写三样：岗位、轮次、派发文件路径。不贴哈希算法、不贴预期哈希、不贴 blocker 原文、不贴岗位卡。子窗交回只留三行，不把这三行再贴进下一轮提示。岗位卡由子窗自己读。主窗不改 `证据/_方案审核派发.md` 和 `证据/_StepNN-代码审核派发.md`。刷新哈希和 `dispatch_revision` 由策划或程序员子窗写。

主窗只做判定和派发。同一方案夹，且口径、选型、A# 相对上一刀没变：不派方案审，派发写 `campaign: yes` 和上一刀 Step 号；隔离代码审仍派。两步及以上、文件不相交、没有 depends-on：同一回复里一起派。有依赖或抢同一文件才一个接一个派。禁止续问同一个子窗。再查就新派，提示只含这一问。细则在 `circuit-windows.md`，用到才打开。

每轮 `[PM]` 加白话「你下一步」。YAML 后一行 token。数字只抄本轮注入。没有本轮注入就写「上一轮未记到」，禁止抄别的对话。满 5 位写成万，保留一位小数，整万不写小数。注入里若有换窗行，必须换行再写「已满足换窗条件, 请执行换窗逻辑减少token消耗」，禁止用空格接在 token 同一行。换窗行只在本对话首次记账后又增加至少 20 万输入时出现。不要因此输出交接全文。

错题大纲有命中时，「你下一步」点名日期或关键词，最多 1 行。没命中写「已扫，无命中」。

派子窗必须写 `model=`。查得到的不问。没测过不许写通过。
