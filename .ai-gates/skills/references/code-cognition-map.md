## 本 Step（分析/改码）

本会话已装载全图之后（未装载则先整节一次）：

1. 用本步**点名**触及对象的 **R** 列出还必须打开的**邻居源码**（R 不是调用图；工具性依赖如通用 `Tools` 公式库不必当强关系）。禁止每刀再灌整节。
2. 再用 CodeGraph 补结构边与原文。
3. 目录有、卡表没有 → `observe`（可改但不当已掌握）。点名实验场景 / 单物体 / 执行窗细节 → `exclude`。
4. 改了受管文件：同 Step **优先改对应卡**；不能改则写「卡片仍准」+ 为何未改。只报「仍准」而无理由 → 交 CR 可 **major**（项目表若有过期检查，从其规定）。

## 写卡纪律（模型写语义）

程序/AST/import 清单**禁止**生成或预填 F/R/A/S。每一条：

- **F**：一个核心职责命题，禁止堆清单。
- **R**：改它必须同看的对象身份（路径/类型名），禁止散文、禁止完整调用清单。
- **A**：对外稳定契约；无则 `-`。禁止把内部方法堆进 A。
- **S**：须同时满足：前四层推不出 **且** 删了会导致改错。口诀/神类止血已写的不重复长抄。
