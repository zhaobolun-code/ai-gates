# 逆链（设计因果闭合 · 倒推审查）

> evolution-02 **第五块**「设计因果闭合」试点。外源脚手架 ≠ 内生反思；**禁止**自报「已反思」。
> **加载本文件 ≠ 启用**逆链；常规任务不跑。

## 节点（硬）

节点 = 既有**选型短表行**（`plan-lite` / `demand-clarification`【本步方案】【为什么】【不选的】）。
**禁止**第四张「逻辑节点」表或独立 `docs/adr/` 与选型短表抢同一件事。
【本步方案】【为什么】【不选的】=判断当时的连接（依据→判断→不选）。禁止交审散文补 why。缺改前三格或三格明显是事后补写 → 该次逆链不得标通过。

## 用途分级（硬）

| 级 | 条件 | 动作 |
| --- | --- | --- |
| **常规** | 普通 Standard/Express | **不启用** |
| **启用** | 高危 / 止损 / 用户点名「逆链」 | 从失败标准 / 冻结表 / 不选的倒推 |

加载本文件（含 reference-routing 自动加载）**不等于**启用。禁止每窗必跑；禁止 Express 默认跑。
高危 / 止损须在 `未完成.md` 或 Mandatory **声明是否启用**；未声明或声明否 = **不启用**。点名「逆链」=声明启用。**默认不启用**。

## Procedure（倒推 · 非正向重写）

1. 提示用 Klein premortem：「已经失败，倒写死因」——禁止「请重构设计思路」。
2. 起点只允许：失败标准、冻结表、【不选的】（每条选型行须有 **Why Not Chosen** + **负向代价** / What Breaks If Violated）。缺任一项 → 该次逆链**不得**标通过。
3. 启用时该 Step 选型短表行 **≤5**（无用户豁免；>5 不得拆第四张表规避）。
4. reverse-premortem：仅当建议推迟/放弃时才写「若放弃是错的，死因是什么」以对冲过严；常规启用不跑。
5. 倒推条目须能回指失败标准 / 冻结表 / 不选的原文；禁止把「为什么」散文正着再写一遍冒充倒推。
6. **骨架倒走 + 断裂检测禁止修补**：倒走只抽出骨架四元组（结论 / 依赖假设 / 关键依据 / 被舍弃备选），每条从失败标准 / 冻结表 / 【不选的】回指。发现断裂只标记，禁止脑补中间步让链变完整（禁止修补）。禁止正着再写 why；禁止提示「请重构设计思路」。该次产出不得比正向选型更完整。

## Never assume intent

禁止从代码 / 实现 / diff **事后**生成 why（与 plan-reviewer 3.9 改前选型相反）。选型必须在改码前。逆链由失败标准 / 冻结表 / 不选的倒推，不由实现反推意图。

## 选型行上限

启用时每 Step 选型短表行 **≤5**。无用户豁免句则 >5 = 失败。禁止另开逻辑节点表把行拆出去规避上限。

## 通过默认（同模型圆稿不合格）

- 默认**异模型抽检**。
- 本机多样性为零（`猜测[无证据]`）→ **必须用户抽检**；禁止把自审写成已通过。
- **同模型圆稿 ≠ 通过**。禁止自审自过；禁止 `resume` 冒充异模型。
- 未完成抽检前禁止写「逆链已通过」。

## 纸老虎

须对照**倒推条目是否落到将改文件 / Mandatory / 冻结表**。只审文档（仅走读 `未完成.md`）不合格。

## 有效倒走 → pending

纸老虎过（回指 A# / 冻结表 / 将改文件）的撑住或断裂 → 写入该窗 `证据/_lesson-pending.md`，标注 `来源：逆链`。键=去项目点名后的设计连接。口头「提及」不加温。禁止逆链内私设热度计。命中进主表后走既有 01-B（近 90 天 ≥2 且最近 ≤30 天）；本页不改脚本阈值。

## 交审后改选型（重开 · 正向手续）

交审后若改选型短表行（含本步方案 / 为什么 / 不选的）：**须重开选型 + 再跑本页逆链**（启用级仍满足时）。这是重开手续，不是「禁止改选型」。
禁止静默改闭环。用户拍板句不得改写。
