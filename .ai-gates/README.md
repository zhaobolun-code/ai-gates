# ai-gates

**AI 几秒就能改出一堆坏代码。正因为如此才要 gates：你用母语提需求，流程交给流水线，降低认知负担。关键节点须人测试通过。**

这套技能从三层一起改 AI 辅助编程：vibe coding 保住手感并收得了尾；自进化让失败变成规则、让做成的办法变成能复用的典故；外源性元认知是对未知的探索。三层底下还垫着两条：**一份真源在 Cursor / Codex / Trae / Claude Code 通用**，**没跑过的不许写成已通过**。想直接看跟同类技能包的差别，跳到[「差别在哪」](#和同类技能包比差别在哪)。

你只管vibe，ai-gates来coding。

## Vibe coding

心流：不纠结语法、不翻文档、不预设完整架构，像画画一样凭感觉把代码构建出来。ai-gates 用你几乎感觉不到的护栏让你勇敢向前，vibe 从玩具变成工具。

- **一个入口**：你只跟「项目经理」说话，说需求、回「准」、按提示验收。写方案、改代码、审代码、写文档由它分派给各自的角色，通常另开对话去做——审查的那一个不知道代码是怎么写出来的，才审得出问题。角色名你不用记。
- **交付闭环**：每个需求一个文件夹；结束后从「执行中」挪到「已签收」。回「准」= 理解 + 方案 + 开工一次确认，每个节点也可以改方案。做完能收尾。
- **止损闭环**：同一做法反复失败就停下来换路，把「此路不通」记进错题本。以后再改这块容易出问题的地方，检查会自动加严（热度）。
- **四车道 + 任务路由**：按改动大小自动选流程——小改几步就完，大改会先写方案再检查，文件变多或跨模块当场加严，你不用自己选。写方案和写代码配普通模型，检查和验收才配更强的模型；再加上「每阶段只点名要用的那一两份规则」，贵模型只花在刀刃上。
- **护栏不只靠自觉**：装好之后，在已接线的客户端（Cursor / Codex CLI / Claude Code；平台差异见[§平台](#平台)）有一层机器门禁——没走流程就改文件会被当场拒绝，改流程设施前必须先写变更日志，`push --force` 这类危险命令直接拦下。被拦时会告诉你原因和怎么放行。
- **不测不算通过**：能自动跑的（编译、你项目里登记过的回归）它自己跑并留证据；跑不了的只能标「未运行」，不许写成已经修好。最后那句「通过」永远是你说的。

传统 vibe 卸掉认知负担之后，同时也卸掉了质量、债务、依赖，小改变成雪崩。gates 把过关标准、停点和关键节点的人测留在流程里。

## 灰箱

你不用每天去读流程说明书，但也不用两眼一抹黑。平时助手只告诉你下一步做什么，你同意了再动手，做到该你试的时候你自己试——省事，但不是瞎干。等你想看看这些事怎么连在一起、哪块还没人做，再打开迷雾地图。很小的改动可以不建新文件夹，地图上也就不会多一块。

- **为什么要有迷雾地图**：事情一多，人和助手都会迷路。人光靠点文件夹看不出「这件事跟哪件有关、接下来该做哪件」；助手也常常只盯着眼前那一个文件夹，不知道旁边还有谁、哪块只提过名字却还没建夹。这张图把已经有的工作文件夹画成一块块地：有文件夹才上图，关系够才连线；只提过名字、还没建文件夹的，画成雾。空着的地方本身就说明还有事没做。
- **为什么好用**：
  - **对人**：连线和空白一眼能看见，不用把几十个文件夹挨个打开。图是根据现有文档自动画的，你不用再维护另一份说明。只有你点头才画；有文件夹也不会自己偷偷画一张。要看细节仍去原来的文档，图只是总览。
  - **对助手**：改某一窗时按连线去读旁边相关的文件夹，避免漏邻居、把还没建夹的名字当成已经做完。图只指路该读谁，正文仍要进文件夹读；不靠这张图了解代码长什么样。
- **打开**：文档状态变了之后，助手会问「是否创建迷雾地图」或「是否更新迷雾地图」。你同意后再生成，然后双击 `.ai-gates/verify/fog-map.html`。直接打开这个文件就行，不要另开网页服务。别的目录里如果还有一份旧图，那份不算。

## 自进化

**两本账**：做错了记进**错题本**，做成了记进**典故**。写方案前两本都先扫一遍——它「越用越好」就靠这两本，没有别的机制。

- **错题本（记坑）**：测试没过先记下；修好后问你准不准写进本项目的错题本；下次写方案会先看；同类问题再出现时检查会更严。目的是同一个错不犯第二次。
- **典故（记已经验证过的做法）**：一件事做成了、办法也验过了，就给它起一个短名字存起来——相当于一份「已验证做法库」。以后你或助手只要提这个名字，整套约定连边界条件一起回来，不必重讲、也不会被换个模型就讲丢；比如「一错不二犯」一提，就是「坑与结构分开记」那一整套。错题本防的是重复踩坑，典故省的是重复解释，两本缺一不可。
- **两本都要你点头，也能给别人用**：错题和典故都要你回「准」才写进本项目，回「准」不等于传到网上；说「上传」才交给公开的收集仓，交出去还要维护者合并，你的窗号和路径不会跟着走。反过来，别人已经长好的部分，你说「项目经理 升级 ai-gates」就能拉回来。

## 元认知（进阶尝试）

有几项进阶检查不在常规流程内，通过选择启用：让两路助手互相找漏洞、从「怎样算失败」往回看设计有没有断、同一轮写出两种看法再对照。已经试过几次（能挖到问题和断点，也更费时间和费用）。日常仍走普通检查。这是技能对未知的探索，不是装上就会自己反思。

## 和同类技能包比，差别在哪

同类大致两种。**工具箱型**：一堆各自独立的技能，你想起来才手动触发——好用，但你得先知道有哪个技能、什么时候该用。**强流程型**：一套固化流程强制走完，AI 从头跑到尾——严谨，但跑起来你插不上手，小改也要走大流程。

ai-gates 的取法是**流程由它选，停点由你说**。下面几条决定长期好不好用，却最容易被忽略：

| 拿什么比 | 同类常见做法 | ai-gates |
| --- | --- | --- |
| **换个编辑器** | 绑定某一个客户端 | 一份真源 `.ai-gates/`，Cursor / Codex / Trae / Claude Code 共用，门禁脚本同源。换工具、换机器，规则不用重装一遍 |
| **说「做完了」** | AI 自己说完就算完 | 三档证据：未运行 / 只静态查过 / 运行已验证。连续两轮只静态查还没测，会被强制停下让你先跑一次 |
| **流程粒度** | 要么全自动接管，要么全靠你手动触发 | 四车道自动选：一行改动一句话就动手，跨模块或碰存档才先写方案再审。你不用自己判断该走哪套 |
| **用久了会怎样** | 技能装完就是那样，不再变 | **两本账**：失败进错题本，同一块地方以后检查自动加严；成功起个短名字进「典故」，一提就带回整套约定。两本都能上传到公开收集仓，再回收给别的项目 |
| **规则多了会不会拖慢** | 规则越写越多，越多越往上下文里灌 | 每阶段最多点名 1–2 份规则，禁止整目录灌入；普通模型写方案和代码，贵模型只用来审 |
| **全局视图** | 靠你自己记项目状态 | 迷雾地图：做过的画成地块、只提过名字的画成雾，人看进度，助手按连线找该读哪个文件夹 |

一句话：**它不替你拍板，但会拦住不该过的东西**——而且这套拦法在换客户端之后、在下一个项目里都还在。

## 30 秒安装，3 分钟熟练

装好之后日常就三件事：提需求、回「准」、按提示在关键节点自己试一遍。

### 方式 A（推荐 · 零手动 · 全平台同一段）

把下面这段**整段**粘贴给 Agent；它会联网取最新版、装库、建好连接并引导初始化：

```text
请把 ai-gates（AI 开发流水线技能包）从 https://github.com/zhaobolun-code/ai-gates 安装到当前项目，替代手动下载、解压和初始化：
- 取最新 release tag，克隆/下载到临时目录；校验根目录有 .ai-gates/ 且 skills/VERSION 是合法 x.y.z 并等于该 tag，不符就停下。
- 把临时 .ai-gates/ 的 skills/hooks/scripts/rules/codex、根文档、hooks.json、link-platform.*、LICENSE 复制到项目根 .ai-gates/；若已装过，先比对版本，仅更新时替换，保留 project-context、mcp.json、hooks-log、tmp、verify、regression-*、pipeline-* 等项目状态。
- 运行 link-platform.ps1（Unix 用 .sh）建传送门，写 install-info.json。
- 运行 pm-init.ps1；说「项目经理 初始化」即可开工（回归索引可后补），生成 .cursor/project-context.md。
- 完成后报告版本与传送门状态，并告诉我以后用「项目经理 + 需求」入口。
动手前先列计划等我确认；失败或网络问题不要改文件，给出手动下载方案。
```

### 方式 B / C（备选）

- **一条命令**（Windows PowerShell，适合批量装）：`powershell -ExecutionPolicy Bypass -c "irm https://raw.githubusercontent.com/zhaobolun-code/ai-gates/main/scripts/install-ai-gates.ps1 | iex"`
- **手动下载**：从 [Releases](https://github.com/zhaobolun-code/ai-gates/releases/latest) 取压缩包，解压到项目根（包内是 `.ai-gates/`），再说 `项目经理 检查健康`。

装好或升级后说一句 `项目经理 检查健康`，它会自己查连接和版本。已装的升级说 `项目经理 升级 ai-gates`。

## 平台

支持 Cursor / Codex / Trae / Claude Code。机器门禁**不是**「所有客户端都会 deny 写入」：Cursor、Codex CLI、Claude Code 可拦；Codex 桌面的 `apply_patch` 可能不触发；Trae 没有机器 hooks。脚本是 PowerShell：Windows 用本机 powershell；macOS / Linux 需要 PowerShell 7（`pwsh`），没装则体检报 `hooks_not_wired_no_pwsh`，只剩规则自觉。机器放行只证明「这会话 120 分钟内说过 `[PM]`」，不证明这一条已经做完结构化判定。平台差异和「被拦了怎么办」详见 [USER-GUIDE](./USER-GUIDE.md)。
